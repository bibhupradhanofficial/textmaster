# TextMaster - Advanced Text Manipulation Utility

TextMaster is a powerful, React-based web application designed to streamline text formatting and conversion tasks. With a modern, glassmorphism-inspired UI and comprehensive feature set, it provides an all-in-one solution for developers, writers, and anyone handling text processing.

## 🚀 Key Features

### 🔠 Text Case Conversion
Instantly transform your text into various formats:
- **UPPERCASE**: Convert all text to capital letters.
- **lowercase**: Convert all text to small letters.
- **Title Case**: Capitalize the first letter of every word (e.g., "Hello World").
- **Sentence case**: Capitalize the first letter of every sentence.
- **aLtErNaTiNg**: Toggle case for each character (e.g., "tExT mAsTeR").

### 🛠️ Formatting Controls
Refine your text layout with precision:
- **Remove Spaces**: Eliminate extra whitespace between words.
- **No Line Breaks**: Convert multi-line text into a single line.
- **Add Line Breaks**: Automatically add line breaks after sentences for better readability.
- **Capitalize First**: Capitalize the first letter of each word (smart casing).

### ⚡ Text Actions
Core utilities for quick operations:
- **Reverse**: Reverse the entire text string.
- **Clear**: Instantly wipe the text area.
- **Copy**: One-click copy to clipboard with preview.

### 🔧 Advanced Tools
Specialized functions for technical needs:
- **Remove Numbers**: Strip all numeric digits from the text.
- **Remove Special Chars**: Clean text by removing special characters.
- **Extract Emails**: Automatically find and list all email addresses from the input.
- **Base64 Encode/Decode**: Securely encode text to Base64 or decode back to plain text.

### 📊 Real-Time Text Analysis
Get instant insights while you type:
- **Word & Character Count**: Track standard metrics.
- **Reading Time**: Estimated time to read the text.
- **Sentence & Paragraph Count**: Analyze text structure.
- **Average Word Length**: Gauge complexity.
- **Common Words**: Identify the most frequently used words.

## 🎨 UI/UX Highlights
- **Dark Mode**: Fully supported dark theme for low-light environments.
- **Glassmorphism Design**: Modern, translucent card effects.
- **Responsive Layout**: Optimized for all device sizes.
- **Interactive Alerts**: Toast notifications for user actions.

## 🛠️ Technology Stack
- **Frontend**: [React.js](https://reactjs.org/) (v17)
- **Routing**: [React Router](https://reactrouter.com/) (v5)
- **Styling**: Bootstrap 5, Custom CSS
- **Tooling**: Create React App, npm

## 📦 Installation & Usage

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/bibhupradhanofficial/textmaster.git
    ```

2.  **Navigate to the project directory**:
    ```bash
    cd textmaster/advanced model
    ```

3.  **Install dependencies**:
    ```bash
    npm install
    ```

4.  **Start the development server**:
    ```bash
    npm start
    ```
    The app will run at [http://localhost:3000](http://localhost:3000).
